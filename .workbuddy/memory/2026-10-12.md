# 2026-10-12

## 排查并修复「摄像头拍照很模糊」

- 定性：原 `camera.py` 只有「相机能不能用」的判定（not_found/unreachable/unknown），**完全没有「拍得好不好」这一层**。糊图照样 base64 喂给 Claude，AI 仍会输出「叶片饱满」之类的结论 —— 属最危险的静默失败。本次同时补上画质可观测性。
- 根因（首要）：**AF 从未被触发**。相机是 Pi Camera v3 = **IMX708（VCM 自动对焦）**，libcamera 不会在 capture 瞬间自动对焦；原流程 `start()` + `sleep(2)` + `capture_file()` 等于盲拍，对焦环可能停在无穷远，拍 0.5~2m 花架必然整幅发虚。全文件搜索确认无 `set_controls`/`autofocus_cycle`/`AfMode`。
- 次要软件根因：① 3A 未收敛（固定 sleep、不读 metadata）；② 未设曝光上限（IMX708 最长 1.72s，清晨拍照必拖影）；③ `1920×1080` 非 IMX708 原生模式（原生仅 4608×2592 / 2304×1296 / 1536×864），ISP 重采样导致偏软；④ 诊断工具只判 `size<20KB`，对「糊」无感知。
- 关键技术发现：**Picamera2 在 `AfMode=Continuous` 下调用 `autofocus_cycle()` 会抛 RuntimeError**（读源码确认）。∴ 静止花架应用 `AfMode=Auto` + 拍照前显式触发，而非 continuous —— 避免了写出必然抛异常的代码。
- 已实施：
  - `hardware/camera.py`：新增 `_wait_for_focus()`（`autofocus_cycle` + 记录 triggered/locked/elapsed/af_state）、`_settle()`（丢 2 帧让 AE/AWB 收敛）、`apply_capture_controls()`（逐个下发 AfMode/AfRange/FrameDurationLimits/AeExposureMode/Sharpness/NoiseReductionMode，单项失败只记 skipped 不中断）、`_save_still()` 改用 `capture_request()` 同帧取元数据（ExposureTime/AnalogueGain/LensPosition/AfState）、`native_mode_hint()` 非原生分辨率告警、`assess_image()` + `judge_quality()` 画质评估与分诊。设计取舍：**对焦失败与画质异常都不阻断拍照**（拍照是浇水/报告流程的一环），只记录 + WARNING + 状态外泄。
  - `config.yaml`：`resolution` 改 `[2304, 1296]`（原生模式、同 16:9 视角）；新增 `autofocus: auto` / `af_range` / `af_wait_sec` / `lens_position` / `max_exposure_us: 66666` / `exposure_mode` / `sharpness_boost` / `jpeg_quality` / `settle_frames` / `quality_guard{min_sharpness:8, min_contrast:12}`。
  - `assistant.py`：新增 `_quality_banner()`，画质告警横幅顶到报告与钉钉消息最前面；`Camera` 构造改传 `capture_settings=cam_cfg`；`status_text()` 展示分辨率提示与上次画质。
  - `tools/camera_diag.py`：`--live` 输出画质指标/对焦过程/拍摄元数据/分诊结论，检查「已生效控件」vs「未生效控件」，`--baseline` 存基线做跨时间对比；退出码新增 **2 = 相机可用但画质异常**。
  - `tests/photoAndAnalyse.py`：拍完直接打印画质指标与建议（现场最直接的验证入口）。
- 清晰度指标标定（本地合成图，纯 PIL 无 numpy/cv2）：清晰 ≈100.1、模糊 0.6px ≈78、1.0px ≈53、1.6px ≈28、2.4px ≈11、4px ≈1.8、纯色 0。默认门槛取 8.0（bad 线 4.8）偏保守，**绝对值与场景强相关**，需现场存基线。
- 发现并修掉两个自身引入/原有缺陷：`parse_capture_settings` 只认 `af_mode` 而 config 写的是 `autofocus`（会导致配置静默失效，被新测试抓到）；`diagnose()` 的 `os.getuid()` 在 Windows 不存在（加 hasattr 兼容 + video 组检查限定 Linux）。
